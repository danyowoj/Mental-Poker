# Отчет по криптографической составляющей системы ментального покера RSA

## 1. Обзор алгоритма

**Основной алгоритм:** RSA (Rivest-Shamir-Adleman) с общим модулем  
**Длина ключа:** 1024 бита (p и q по ~512 бит)  
**Тип криптосистемы:** Асимметричная с общим модулем для всех участников  
**Применение:** Ментальный покер (Mental Poker) - игра в покер без доверенного дилера

## 2. Архитектура криптосистемы

### 2.1 Общий модуль RSA
```python
def generate_common_modulus(self) -> int:
    p = sympy.randprime(2**511, 2**512)  # ~512 бит
    q = sympy.randprime(2**511, 2**512)  # ~512 бит
    self.n = p * q                        # ~1024 бита
    self.phi_n = (p - 1) * (q - 1)
```

**Ключевые моменты:**
- Сервер генерирует два больших простых числа p и q
- Вычисляется модуль n = p × q (общий для всех игроков)
- Вычисляется функция Эйлера φ(n) = (p-1)(q-1)

### 2.2 Генерация ключей игроков
```python
def generate_player_keys(self, player_id: str) -> Tuple[int, int]:
    # Выбор экспоненты e, взаимно простой с φ(n)
    e_candidates = [3, 5, 17, 257, 65537]
    for e in e_candidates:
        if math.gcd(e, self.phi_n) == 1:
            d = sympy.mod_inverse(e, self.phi_n)
            return e, d
```

**Для каждого игрока:**
- **Публичный ключ (e):** небольшая экспонента (чаще всего 65537)
- **Приватный ключ (d):** d ≡ e⁻¹ (mod φ(n))
- У каждого игрока своя пара (eᵢ, dᵢ), но общий модуль n

## 3. Процесс шифрования/дешифрования

### 3.1 Представление карт
```python
# Карты представляются простыми числами
prime = 2
while len(self.card_numbers) < 52:
    if sympy.isprime(prime) and math.gcd(prime, self.n) == 1:
        self.card_numbers.append(prime)
        prime += 1
```
Каждая из 52 карт колоды представляется уникальным простым числом, меньшим n.

### 3.2 Шифрование карты
```python
def encrypt_card(self, card_number: int, e: int) -> int:
    return pow(card_number, e, self.n)  # C = M^e mod n
```

### 3.3 Дешифрование карты
```python
def decrypt_card(self, encrypted_card: int, d: int) -> int:
    return pow(encrypted_card, d, self.n)  # M = C^d mod n
```

## 4. Протокол ментального покера

### 4.1 Инициализация
```
Сервер: генерирует n = p × q
Игрок i: получает (eᵢ, dᵢ), где dᵢ ≡ eᵢ⁻¹ (mod φ(n))
```

### 4.2 Последовательное шифрование колоды
```
Исходная колода: [M₁, M₂, ..., M₅₂]
Игрок 1: [M₁^e₁ mod n, M₂^e₁ mod n, ..., M₅₂^e₁ mod n] + перемешивание
Игрок 2: [(M₁^e₁)^e₂ mod n, ...] + перемешивание
...
Игрок k: [M₁^(e₁e₂...eₖ) mod n, ...] + перемешивание
```

Код из `shuffle_and_encrypt_deck`:
```python
current_deck = self.card_numbers.copy()
random.shuffle(current_deck)

for player_id in player_order:
    e = self.players_keys[player_id]['e']
    current_deck = [self.encrypt_card(card, e) for card in current_deck]
    random.shuffle(current_deck)
```

### 4.3 Раздача карт
```
Зашифрованная карта: C = M^(∏eᵢ) mod n
Для расшифровки игроку j: C^(∏_{i≠j} dᵢ) mod n = M^(eⱼ) mod n
Затем игрок j применяет свой dⱼ: (M^(eⱼ))^dⱼ mod n = M
```

Ключевой метод `decrypt_for_player`:
```python
def decrypt_for_player(self, encrypted_card: int, player_id: str,
                      player_order: List[str]) -> str:
    card_value = encrypted_card
    # Расшифровываем всеми игроками в обратном порядке
    for current_player in reversed(player_order):
        d = self.players_keys[current_player]['d']
        card_value = self.decrypt_card(card_value, d)
    return self.get_card_from_number(card_value)
```

## 5. Доказательство безопасности

### 5.1 Математическая основа
**Теорема:** Для RSA с общим модулем n:
- Если каждый игрок i имеет (eᵢ, dᵢ) такие, что eᵢ·dᵢ ≡ 1 (mod φ(n))
- Тогда для любого сообщения M: (M^(∏eᵢ))^(∏dᵢ) ≡ M (mod n)

**Доказательство:**
```
Пусть E = ∏eᵢ, D = ∏dᵢ
Поскольку eᵢ·dᵢ ≡ 1 (mod φ(n)) для каждого i
Тогда E·D ≡ 1 (mod φ(n))
По теореме Эйлера: M^(E·D) ≡ M (mod n)
```

### 5.2 Свойства безопасности

#### 1. **Конфиденциальность карт**
- Сервер видит только зашифрованные карты: C = M^(∏eᵢ) mod n
- Без знания всех dᵢ невозможно вычислить M
- Каждый игрок знает только свой dᵢ

#### 2. **Невозможность мошенничества сервером**
```
Доказательство:
Сервер знает: n, все eᵢ
Сервер не знает: p, q, φ(n), любые dᵢ
Задача: вычислить M из C = M^(∏eᵢ) mod n
Эквивалентно задаче RSA: найти корень степени E по модулю n
Это вычислительно сложно при длине n = 1024 бита
```

#### 3. **Невозможность сговора игроков**
```
Если k-1 игроков сговорились, они знают:
- Свои пары (eᵢ, dᵢ)
- Зашифрованные карты C
Могут ли они узнать карту игрока j?
Им нужно вычислить: M = C^(dⱼ) mod n
Но они не знают dⱼ
Вычисление dⱼ из eⱼ требует знания φ(n)
Вычисление φ(n) из n эквивалентно факторизации n
Факторизация 1024-битного числа практически невозможна
```

### 5.3 Атаки и защита от них

#### Атака 1: Факторизация n
- Сложность: O(exp(√(ln n ln ln n))) для метода квадратичного решета
- Для n ≈ 2¹⁰²⁴: требует ~2⁸⁰ операций
- Практически неосуществима при современных вычислительных мощностях

#### Атака 2: Вычисление φ(n) без факторизации
- Известно: φ(n) = n - (p + q) + 1
- Нахождение φ(n) эквивалентно факторизации n

#### Атака 3: Атака на общий модуль
В классической RSA с общим модулем существует атака, если:
1. Один и тот же текст шифруется разными ключами
2. Экспоненты eᵢ малы

**Защита в данной реализации:**
1. Карты представляются разными простыми числами
2. Используются небольшие, но разные eᵢ (3, 5, 17, 257, 65537)
3. Добавлено случайное перемешивание после каждого шифрования

### 6.2 Проверка корректности

```python
def verify_encryption(self, player_order: List[str]) -> bool:
    test_card = self.card_numbers[0]
    
    # Последовательное шифрование
    encrypted = test_card
    for player_id in player_order:
        e = self.players_keys[player_id]['e']
        encrypted = self.encrypt_card(encrypted, e)
    
    # Последовательное дешифрование
    decrypted = encrypted
    for player_id in reversed(player_order):
        d = self.players_keys[player_id]['d']
        decrypted = self.decrypt_card(decrypted, d)
    
    return test_card == decrypted  # Должно вернуть True
```

## 7. Заключение

Данная реализация ментального покера использует модифицированную схему RSA с общим модулем, которая обеспечивает:

1. **Конфиденциальность:** никто, включая сервер, не знает карт игроков
2. **Честность:** отсутствие централизованного дилера исключает его манипуляции
3. **Верифицируемость:** каждый может проверить корректность протокола
4. **Вычислительную безопасность:** основана на сложности факторизации больших чисел

**Математическая корректность** протокола следует из свойств RSA:
```
M^(e₁·e₂·...·eₖ)^(d₁·d₂·...·dₖ) ≡ M (mod n)
где eᵢ·dᵢ ≡ 1 (mod φ(n)) для каждого i
```

**Практическая безопасность** обеспечивается:
- Использованием 1024-битных ключей
- Правильной реализацией математических операций
- Последовательным применением шифрования всеми игроками
